## 核心节点说明

### 路由节点 (route_by_workflow)
- **位置**: 招标文件解析后
- **功能**: 根据 `workflow` 参数路由到不同分支
- **分支**:
  - `check` → check_workflow 分支
  - `generate` → generate 分支
  - `knowledge` → 知识库管理模块

### 人工节点
- **位置**: 生成流程中，招标文件要求解析后
- **功能**: 人工审核点，可触发后续自动任务
- **标注**: 图中显示为"人"形图标

### 汇聚节点
- **位置**: 并行任务完成后
- **功能**: 汇聚多个并行任务的输出
- **标注**: 图中显示为小圆圈

## 技术栈

- **前端**: Streamlit
- **工作流**: LangGraph (StateGraph)
- **AI**: 豆包大模型 (deepseek-v3-2-251201)
- **搜索**: 联网搜索 + 本地知识库
- **存储**: Git LFS + JSON 索引 (KnowledgeIndex)
